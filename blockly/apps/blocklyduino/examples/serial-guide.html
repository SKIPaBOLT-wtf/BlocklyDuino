Editor · Monitor · Plotter

Talk to the board and see its data

Monitor is a text terminal with a send box. Plotter turns the same stream into instruments and images. Both may remain open together: the local service opens the port once and gives each view a copy. Connect/disconnect and baud changes affect the shared port; view pause, display filters and captures are local.

Connect

  1. Upload a lesson from the editor first.
  2. Open Monitor or Plotter, select the serial port and match the sketch's baud. The current Plotter lessons use 115200. Refresh ports after connecting an adapter.
  3. Press Connect/apply. The last successful port and baud are remembered. Opening a tool alone does not open hardware.

Connection can reset a board through DTR. Upload releases the port and reconnects it if it was previously open. An external Arduino IDE monitor must release the port before this service can use it. Closing one of these views does not disconnect the shared port.

Send commands

Type in Monitor and press Send or Enter. Choose LF, CRLF, CR or no line ending. The up/down arrows recall recent commands. Example 54 echoes bytes at 115200 baud without waiting for a whole line.

Use serial bytes available before serial read byte. Read returns 0–255, or -1 when empty. Serial write byte sends the raw character value; serial send prints its numeric/text representation.

Start a Plotter lesson

Choose Auto / controller header and press Start. Plotter sends START\n. The lesson replies with its header and data. Stop sends STOP\n; the port stays connected. Pause view only freezes the display while reception and capture continue. The examples parse complete command lines with a five-byte array rather than a blocking String read.

The full Plotter guide describes exact headers, multiple instruments, images, derived mathematics and live configuration changes.

Keep data in view and save it

Collapse Settings and diagnostics once configured; the tool remembers their state. Save/export profiles to reuse a layout. History controls rolling chart display; Capture retains a chosen number of upcoming samples/pixels independently. CSV/JSONL captures include configuration revisions, so live header changes remain interpretable. Save image exports the retained image as PNG; raw capture retains original pixel values.

Monitor Save log exports its retained text. Plotter capture remains in browser memory until exported. Baud rate is remembered; different captures/profiles belong to this browser and local origin unless exported. See the full guide for limits and file formats.
