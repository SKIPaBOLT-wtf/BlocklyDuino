Editor guide · Serial Plotter

Build an image one measurement at a time

The microcontroller sends coordinates and a measurement. The Plotter holds the image in the computer’s memory: updating one pixel keeps all other pixels intact. Pixels may arrive in any order, and later scans overwrite only the coordinates they send. Images always fit the available view while PNG export uses the original resolution.

Try it

  1. Open Plotter → Scan image → Try image demo. No board is needed.
  2. For a real scanner, open example 61: photocell and two servos. It uses pan signal D9, tilt D10, and analog sensor A0 on Pro Mini/Uno. Connect a photocell as a voltage divider, not as an unconnected resistance. Servo power must meet the servos’ current requirement; connect its ground to the board ground.
  3. Compile/upload when wired. Open Monitor or Plotter and connect at 115200 baud. The two tools share the connection; Monitor still shows the same incoming text.
  4. The example scans 64 × 48 pixels, reading one value after a 20 ms settling delay. A full scan takes roughly a minute. Adjust settling time to your mechanics. The example deliberately limits pan to 35–145° and tilt to 45–135°; edit all map values for your rig.
  5. Choose Save PNG at any point. Unmeasured pixels are transparent. Clear image is explicit; the image is never erased between scan passes.

Protocol

Send one header in setup, followed by newline-terminated pixel rows. Coordinates start at zero, with (0,0) in the top-left corner.

@image {"version":1,"id":"photocell","width":64,"height":48,"mode":"gray","max":1023}
@pixel 0,0,512
@pixel 1,0,1023
@pixel 0,1,0

max is the maximum incoming channel value, not a fixed number of palette entries. Any finite positive maximum is accepted, including 1023, 4095, 65535, or a fractional measurement range. Values must be between zero and max. The view maps that range to 0–255 per channel. PNG export contains these 8-bit display values; use the existing SD PGM/PPM blocks when you need to preserve higher bit depth in a file.

@image {"version":1,"id":"colour","width":320,"height":240,"mode":"rgb","max":255}
@pixel 12,8,255,128,0
@image-clear

RGB rows contain x,y,red,green,blue. One image is active per Plotter window. Repeating an identical header preserves the existing image. A changed id, size, mode or maximum starts a new image. @image-clear explicitly clears it. Invalid commands are reported without changing existing pixels. The maximum is 16,777,216 pixels and 16,384 per dimension, to bound browser memory and canvas size (up to 64 MiB for the pixel buffer, plus rendering copies).

Blocks and controls

Text & serial contains scan image, scan pixel gray, scan pixel RGB and clear scan image. Width, height, maximum, coordinates and channel values accept variables and calculations. No JSON library or image buffer is added to the Arduino sketch.

A header opens the image view. You can then switch between Charts and Scan image without incoming pixels taking focus back. Pause view freezes drawing while reception continues; Save PNG exports the latest received image. Image pixels are separate from the chart sample capture/CSV feature. Reloading or closing the Plotter clears the in-memory image, so save it first if needed.
