Scan without an Arduino image buffer

Example 61 uses a light-sensor divider on A0 and two servos. Example 75 paints a synthetic RGB image with no extra hardware. Upload, connect Plotter at 115200 baud, choose Auto and press Start.

SignalPro Mini ATmega168 / 16 MHz
Pan servoD9 / OC1A
Tilt servoD10 / OC1B
Light divider outputA0, within GND–VCC
Servo powerSuitable servo supply, common GND

Both servo outputs share Timer1 hardware PWM and the same refresh period. Timer1 is then unavailable to fast stepper/audio/timer-interrupt engines. Adapt the angle range to your mechanics. The example waits 80 ms between positions without delay(), reads light, sends one pixel and requests the next position. Increase the interval if settling needs longer.

Header: image plus chart

@plot {"version":1,"id":"camera","fields":[{"id":"light","min":0,"max":1023}],"widgets":[{"type":"image","image":{"id":"scan","width":32,"height":24,"mode":"gray","max":1023}},{"type":"line","fields":["light"]}]}

This is a normal serial text message, emitted after START. Click its compact field to edit the formatted JSON. No image-specific Arduino block is needed.

Data: coordinates and values

@pixel scan 0,0,512
@data {"id":"camera","t":80,"values":[512]}
@pixel scan 1,0,700
@data {"id":"camera","t":160,"values":[700]}

X is 0–31, Y is 0–23. Any order is accepted. A repeated coordinate replaces that pixel only. Each image has its own ID/dimensions. The canvas fits the visible area while retaining its configured resolution.

For RGB use "mode":"rgb","max":255, then @pixel scan x,y,r,g,b. Larger ranges such as max 1023 are normalized for display. PNG export uses 8-bit channels; capture raw pixel records when greater input precision matters.

@image-clear scan explicitly clears a frame. A new header resets the image; completing a raster does not. Stop asks the sketch to stop; Pause view keeps reception/capture running. Save image exports the current frame. Capture stores pixel updates and header revisions alongside numeric records.

Memory and scan speed

The AVR holds coordinates, measurement, timing and a five-byte command buffer. The PC stores all pixels. More pixels increase scanning time and PC memory, not an AVR framebuffer. Serial bandwidth and mechanical settling remain the useful speed limits. Separate SD examples stream BMP/PGM/PPM files when no computer is attached.
